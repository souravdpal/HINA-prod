# Docker MCP Server

This is a boilerplate Model Context Protocol (MCP) server ready to run inside a Docker container.

## Building the Docker Image

```bash
docker build -t mcp-server-docker .
```

## Running locally

To run it interactively (via stdio):

```bash
docker run -i --rm mcp-server-docker
```

## Claude Desktop Integration

To integrate this Dockerized MCP server with Claude Desktop, add the following config to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "docker-mcp-server": {
      "command": "docker",
      "args": [
        "run",
        "-i",
        "--rm",
        "mcp-server-docker:latest"
      ]
    }
  }
}
```
